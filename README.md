# キャラクター拳銃診断

創作キャラクター向けの「似合う拳銃診断」Webサイトです。

キャラクター名を入力し、いくつかの質問に回答すると、その人物の性格・美意識・道具の好み・立ち位置などから、似合いそうな拳銃を1丁表示します。

実銃の性能比較や購入推奨を目的としたものではなく、創作キャラクターのイメージ作りを目的とした診断です。

## 使い方

1. `index.html` をブラウザで開きます。
2. キャラクター名を入力して `START` を押します。
3. 質問に回答します。
4. 診断結果として、似合う拳銃とキャラクター傾向が表示されます。

サーバーやデータベースは不要です。

## ファイル構成

```text
キャラクター拳銃診断/
├── index.html
├── style.css
├── script.js
└── README.md
```

- `index.html`  
  画面構造を定義しています。

- `style.css`  
  レイアウト、フォント、色、ボタン、結果画面などの見た目を定義しています。

- `script.js`  
  質問内容、拳銃データ、診断ロジック、結果表示を管理しています。

## 診断の仕組み

回答ごとに複数の性質へ点数を加算し、各軸を0〜5に正規化したうえで、キャラクター全体の傾向と各拳銃のプロフィールの方向性を比較して結果を決めています。

主な診断軸は以下です。

- STYLE：見た目や演出性
- PRACTICAL：実用性
- CLASSIC：古典的なものへの好み
- MODERN：現代的なものへの好み
- ELEGANT：上品さ
- RUGGED：無骨さ
- UNIQUE：個性・珍しさ
- MECHANICAL：機構や構造への興味
- PROFESSIONAL：仕事道具としての合理性
- COMPACT：控えめさ・小型志向
- EXPERIMENTAL：変則設計や実験的なものへの興味

結果画面では、このうち主要な項目を5段階メーターで表示します。

## 診断結果

現在の結果候補は以下です。

- Colt Python / コルト・パイソン
- Beretta 92FS Inox / ベレッタ 92FS イノックス
- Glock 17 / グロック 17
- H&K USP
- SIG Sauer P226 / SIG ザウエル P226
- Walther P99 / ワルサー P99
- CZ 75
- M1911
- Browning Hi-Power / ブローニング・ハイパワー
- Walther PPK / ワルサー PPK
- Desert Eagle / デザートイーグル
- FN Five-seveN / FN ファイブセブン
- Ruger P85 / ルガー P85
- Kel-Tec P50 / ケルテック P50
- Apache Revolver / アパッチ・リボルバー

Kel-Tec P50 と Apache Revolver は、通常の結果よりも条件を厳しくした特殊寄りの結果です。

Kel-Tec P50 は「未来的な珍品」と「普通じゃない」を選び、UNIQUE・EXPERIMENTAL・MODERNが高い場合に候補になります。

Apache Revolver は「古くて奇妙な珍品」と「普通じゃない」を選び、UNIQUE・EXPERIMENTAL・CLASSIC・MECHANICALが高い場合に候補になります。

## 注意

このサイトは創作向けのイメージ診断です。

表示される結果は、実銃の安全性・性能・適性・法的な所持可否などを評価するものではありません。

## 結果画像

結果画面の画像は、Wikimedia Commons、Unsplashなどから、再利用条件を確認できる写真を使用しています。PICRYLも候補として検索し、対象の拳銃そのものが写っており、構図と利用条件の両方が適している場合に採用します。

各画像の下に、撮影者・出典・ライセンスを表示します。画像は外部URLから読み込むため、オフライン環境や画像配信元へ接続できない環境では表示されない場合があります。

Ruger P85については、再利用条件が明確なP85そのものの画像を確認できなかったため、同じRuger PシリーズのP89画像を参考画像として表示しています。

## 画像ライセンスについて

CC BY-SA画像は、結果画面で作者名・出典ページ・Creative Commonsライセンスへのリンクを表示します。改変済みの画像を使用する場合は、その旨も表示します。

CC0およびパブリックドメイン画像は、法的に必須ではない場合もありますが、確認しやすいよう出典と作者・機関名を表示しています。

Unsplash画像はUnsplash Licenseに基づいて使用し、結果画面からライセンスページへリンクします。
